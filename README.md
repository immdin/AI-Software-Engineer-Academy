# AI Software Engineer Academy

Личная образовательная академия: PWA для Android, работает офлайн.
Стек: React + TypeScript + Vite + vite-plugin-pwa. Публикация: GitHub Pages.

Текущая стадия: **Шаг 0**, проверка цепочки публикации и установки.

## Публикация (один раз)

1. В репозитории: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. Закоммитить файлы в ветку `main`. Workflow `.github/workflows/deploy.yml` соберёт и опубликует сайт.
3. Адрес: `https://<логин>.github.io/<репозиторий>/`

## Проверка на Android

См. чек-лист в сообщении Шага 0.

## Безопасность репозитория

Репозиторий публичный (требование бесплатного GitHub Pages). Не кладите сюда пароли,
ключи с правами записи и персональные данные.
